# DiffusionDrive Selector Oracle R1.5 Result

Date: 2026-09-03

## Decision

The immutable causal gate returned:

`AUTHORIZE_CURRENT_SET_CAUSAL_METHOD`

R1.5 therefore establishes that, in multiple failed Reactive development
scenarios, the frozen V3 generator already contained a better action and a
single pre-action candidate substitution was sufficient to recover closed-loop
success. This is a causal selector-bottleneck result, not merely an offline
reward-ranking correlation.

## Audited result

All eight intervention collections passed split and merged audits. Candidate,
logit, action-conversion, treatment, worker, scenario, checkpoint, code, and
outcome provenance checks passed. Maximum action parity error was below
`1.8e-5`, against the registered `1e-4` limit.

| Arm | Target units | Reward-stable units | Reward-stable distinct scenes | Rescued distinct scenes | Mean score delta | Descriptive bootstrap 95% |
|---|---:|---:|---:|---:|---:|---:|
| One-shot oracle | 12 | 11 | 7 | 5 | +0.488522 | [+0.197271, +0.783700] |
| Persistent oracle | 12 | 11 | 7 | 5 | +0.574351 | [+0.258971, +0.862805] |

The one-shot arm already passed the primary gate. Persistent intervention
rescued the same number of distinct scenes; it improved one additional
seed-scene unit but did not add a new rescued physical scene. The current-set
mechanism therefore has priority over a temporal-override mechanism.

The smoke and formal collections shared four target units per arm. All eight
arm/target outcome comparisons reproduced exactly, including successes and
failures.

## Interpretation boundaries

1. The causal existence claim passes: current-set misselection is a real
   closed-loop bottleneck for V3.
2. The one-shot result says a sequential override is not required for the
   primary mechanism claim.
3. R1.5 does not show that the selector's current inputs can identify every
   rescuing candidate without the diagnostic oracle.
4. All selected baseline failures have score zero, so score deltas are
   lower-bounded by zero. The bootstrap interval is descriptive; the meaningful
   evidence is rescue in five distinct reward-stable scenes.
5. The sample is diagnostic and development-only. It is not a certification
   result and must not be used as training data.
6. Pairwise-normalized `ego_progress` was rerun-sensitive in 24/58 paired
   initial states, while candidates and the other five reward components were
   exact. The frozen-treatment sensitivity gate must remain in all claims.

## Consequence for the next method

R1.5 reopens a current-set method, but it does not revive previously rejected
global full-feedback, generic ranking, static proximal, or top-1 verifier
variants. Those methods improved suppressed cases while damaging V3-solved
cases, or could not identify safe overrides.

The next experiment should isolate the missing quantity: whether a candidate's
local scalar advantage predicts the downstream causal value of selecting it.
Use training-split scenarios only, branch the same frozen diffusion set at a
state into the V3 incumbent and a small number of preregistered challengers,
apply one candidate once, then return control to frozen V3. The resulting
paired downstream return is a selector-only counterfactual label generated by
the simulator, not an external scene label or inference-time evaluator.

Only if these training-only branch returns are repeatable and predictable from
selector-visible set context should a causal setwise post-training objective be
implemented. Otherwise the honest conclusion is that the information needed
for safe override is absent from the current selector input, despite the causal
action opportunity established here.
